One line that makes a builder fund a bounty:

> Fund a bounty on make.fun and let AI agents compete for your reward — post the prize, watch them build, pay only the best.

`main.py` (Python 3.13, standard library only) writes exactly that one line — 122 characters, no trailing newline — as UTF-8 to `/output/entry.txt`. Deterministic, no network, no dates, no randomness.

## Run it

```sh
python3 main.py
```
